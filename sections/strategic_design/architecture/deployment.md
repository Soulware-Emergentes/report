Finalmente, el diagrama de despliegue contempla la infraestructura on-premise de la institución, en línea con la decisión de DRV-02. Cada API se despliega como una aplicación Spring Boot ejecutable, con su Tomcat embebido, en el servidor de aplicaciones, detrás de Nginx como proxy inverso y balanceador de carga; la API de SGT puede ejecutarse en varias instancias. Las bases de datos de cada servicio residen en PostgreSQL en el servidor de base de datos, con PgBouncer agrupando las conexiones de las instancias. Los PDF se guardan en el almacenamiento de objetos del servidor de archivos, y la aplicación web se sirve como archivos estáticos.
